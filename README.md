# QQ群管理 · astrbot_plugin_qq_group_manager

面向 **QQ 官方机器人（qq_official）** 的 AstrBot 群管理插件：群档案与平台能力自检、
基于 AstrBot 已配置 LLM 的群消息合法性识别与处置（警告 / 撤回 / 禁言 / 上报）、
入群申请智能审批、群成员禁言与黑名单管理；SQLite 审计库 + WebUI 管理台。

> 平台能力与 AstrBot 接口的调研结论见 docs/平台能力调研.md，完整设计见 docs/设计方案.md。

## 功能（M1 已可用）

- **群档案**：群名称 / 简介 / 分类 / 标签 / 人数，机器人群内角色、消息接收设置、是否可主动推送。
- **能力自检**：逐项探测「群信息 / 群状态 / 是否管理员 / 接收全部消息 / 撤回 / 禁言 / 入群审批 / 成员列表 / 黑名单 / 批量移除」，
  受限（如 `err_code=11253` 需白名单）会**记录日志并在 WebUI 展示**，不会崩溃或刷屏。
- **群列表**：群内收到消息即自动登记（含群名、最后活跃时间），也可在 WebUI 手动添加。
- **审核开关（带前置校验）**：启用审核前强制检查「接收全部消息」，未开启时直接拒绝并给出操作指引；
  后台每 30 分钟复查，能力丢失会自动暂停审核并告警。
- **审计库（SQLite）**：审核事件、处置动作、API 调用、能力受限、入群申请、禁言台账、日统计，全部可查询、可导出。
- **WebUI 管理台**：总览（运行状态 / 统计 / 后台任务 / 能力受限告警）、群管理、日志中心（4 类日志 + 筛选 + 导出 + 清空）、
  工具（能力自检、审计库维护与备份、SSE 实时事件、指令速查、配置摘要）。
- **LLM 内容审核**：本地规则（关键词/正则/外链/联系方式/刷屏/超长）→ LLM 严格 JSON 判定（分类/严重度/置信度）→ 按矩阵处置；
  含相同文本缓存、采样率、单群 QPM、全局并发、日预算、连续失败熔断；解析失败一律降级为「需复核」且不处置。
- **处置执行**：警告（被动回复）、撤回（需群管理员且 2 分钟内）、禁言（时长阶梯 + 重复违规累加，≤30 天）、拉黑、移除（默认关闭）、上报管理员；
  能力不可用时自动降级并留痕；同一消息幂等，平台重复推送不会重复处置。
- **申诉**：成员回复被处置消息并发送 `申诉 <理由>`，事件会标记申诉并通知管理员。
- **入群审批**：轮询申请列表 → 硬规则（黑名单/机器人/平台风险提示/信任邀请人）→ LLM 判定 → 自动审批或转人工；
  官方「入群自动审批策略」在管理台透明展示（含与插件审批的冲突检测）。
- **成员管理**：禁言/解禁、禁言台账（每 5 分钟与平台对账）、成员查询（本地缓存 + 内邀接口）、黑名单（平台 + 本地双轨）、批量移除（二次确认）。
- **指令**：`群管理菜单`、`群信息`、`审核状态`、`申诉`、`审核开启/关闭`、`审核模式`、`审核阈值`、
  `关键词`、`信任/取消信任`、`禁言/解禁`、`撤回`、`审核日志`、`审核统计`、`入群审核`、
  `入群申请`、`入群通过/入群拒绝`、`黑名单`、`群管理自检`、`群管理配置`。

## 安装

1. 把本目录放到 AstrBot 的插件目录：

   ```bash
   cd AstrBot/data/plugins
   git clone https://github.com/td1336065617/astrbot_plugin_qq_group_manager
   ```

2. 在 AstrBot WebUI →「插件管理」中确认插件已加载（无第三方依赖，不需要额外安装 pip 包）。
3. 打开插件卡片 →「管理台」进入 WebUI 页面；在「群管理」里对目标群执行一次**能力探测**。
4. 若要在某群启用内容审核：先用手机 QQ 打开该群 → 设置 → 机器人 → 选中本机器人 → 打开「接收全部消息」，
   然后回到管理台点击「启用审核」。

## 权限与平台限制（必读）

QQ 官方平台对群管理接口有明确的能力门槛，插件会如实呈现而不是隐藏功能：

| 能力 | 门槛 | 插件表现 |
| --- | --- | --- |
| 群基本信息、机器人群内状态 | 仅**白名单**机器人（`err_code=11253`） | 显示"平台未授权"，其余功能不受影响 |
| 入群申请列表/审批、禁言、撤回 | 机器人需为**群管理员** | 非管理员时禁用并在界面提示 |
| 群成员列表/详情、批量移除、黑名单 | 白名单 + **内邀接入中** | 调用失败会记录日志，界面标注"内邀未开放" |
| 接收全部消息 | 群管理员在机器人资料页开启 | 未开启时**不允许启用内容审核** |

其它平台事实：撤回仅限 **2 分钟内**且需管理员；禁言单次 ≤20 人、**最长 30 天**、只能操作普通成员；
群消息默认只有 **@机器人** 的才推送；**没有**主动退群 / 群公告 / 设置管理员 / 全员禁言写入 / 解散群等接口。

## 指令

| 指令 | 权限 | 说明 |
| --- | --- | --- |
| `群管理菜单` | 所有人 | 显示菜单 |
| `群信息` | 所有人 | 群档案与机器人在群状态 |
| `审核状态` | 所有人 | 本群审核开关、模式、暂停原因 |
| `群管理自检` | AstrBot 管理员 | 平台能力探测与错误码诊断 |
| `群管理配置` | AstrBot 管理员 | 提示管理台入口 |

指令为**全匹配**（可带 `/` 前缀），不会误伤普通聊天。

## 开发

```bash
# 运行测试（需要 AstrBot 的运行环境，用于导入 astrbot 与 botpy）
python -m pytest -q

# 代码风格
python -m ruff format .
python -m ruff check .
```

目录结构：

```text
astrbot_plugin_qq_group_manager/
├── main.py              # Star 入口：服务装配、生命周期、消息与指令处理

├── menu.md              # 供 menu_navigation 聚合的菜单
├── ruff.toml            # 本插件的 lint 配置
├── pages/manage/        # WebUI 管理台（单页 SPA：index.html / app.js / style.css）
├── src/
│   ├── api_client.py    # QQ 官方接口客户端（限频、重试、错误码语义、dry-run、能力探测）
│   ├── audit.py         # SQLite 审计库（批量写队列、查询、裁剪、备份）
│   ├── commands.py      # 指令文案与自检报告
│   ├── models.py        # 数据模型与常量（能力、错误码、默认配置）
│   ├── scheduler.py     # 后台周期任务
│   ├── store.py         # 配置与状态（KV）+ 并发保护
│   ├── utils.py         # 时间/文本/时长工具
│   └── web_api.py       # WebUI 后端接口（REST + SSE）
└── tests/               # 47 个单元/契约测试
```
